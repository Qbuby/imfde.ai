# 情报验收标准 · 二 · 展示（Display Standard v2.0）

> 管「合格的情报怎么摆到读者眼前，使读者收到的意思 = 我们想表达的意思」。
> 依据：Kent 1964「serious possibility」事故（作者 65:35、读者远低于此、同事 20:80–80:20）；ICD 203 #8「读者收到的应是分析员想表达的」；NIE Key Judgments 须可独立成篇；市场做法见 `docs/research/product-form-comparison.md`。

## 0. 唯一目标

**读者在 20 秒内得到的结论，必须与情报员想表达的一致。** 一切版式服务这一条。

## 1. 三层阅读契约

| 层 | 时长 | 内容 | 硬约束 |
|---|---|---|---|
| **L1** | 20 秒 | 判断句 + likelihood + confidence + 跨期状态 | **遮住 L2/L3 仍成立，且不产生误读** |
| **L2** | 3 分钟 | 事实 / 判断 / 假设 / 反证 / 替代解释 | 每句判断能就地看到来路 |
| **L3** | 需引用时 | 来源表、口径、快照状态、下期核对、改判记录 | 能走到原始材料并看到历史改判 |

## 2. 固定版式（不得自创）

```
L1
  判断句            ≤24 字，首句即主信息，不铺垫
  Likelihood        七档词表之一（单独一行）
  Confidence        低/中/高 + 一句话依据（不得与 likelihood 同句）
  跨期              首次 / 与上期一致 / 变更（附依据）
  存量标记          本期新增 / 截至某日存量 / 长期背景

L2
  【事实】n 句，每句带来源码与口径
  【判断】从哪几条事实推出，哪一步是推断
  【假设】显式；若假设错，判断变成什么
  【反证】削弱本判断的事实 / 未披露项
  【替代解释】≥1 + 区分指标

L3
  来源表（发布者/日期/类型/立场/获取方式/快照状态）
  同源簇、口径、原文链接
  下期核对（谁 + 何时 + 可观测动作）
  改判记录（日期 / 触发信息 / 旧判断错在哪）
  观测盲区（本产品管线自身的缺口）
```

## 3. 措辞受控

| 类别 | 允许 | 禁止 |
|---|---|---|
| 事实 | 发布、宣布、公布、披露、上线、签署 | 证明、标志着、意味着 |
| 计划 | 计划、目标、承诺、拟、预期 | 完成、实现、落地 |
| 判断 | 我们判断、据此推断、更可能是 | 显然、无疑、必然、事实是 |
| 不确知 | 该来源未披露、我们未核实、证据不足 | 没有、为零、不存在 |

- likelihood 只用 ICD 203 七档；`possible` 类词不得加修饰（Kent 原则）。
- **confidence 与 likelihood 不得同句。**
- 「未取得正文」不得写成「未报道」「不存在」。

## 4. 视觉编码

| 用 | 不用 |
|---|---|
| 左竖线/淡底分区（事实/判断/假设/反证） | 颜色深浅暗示重要性 |
| 定位置小标签（B1/C2/D2/F6、获取方式） | 红绿表示可信不可信 |
| 时间线表达顺序与跨期 | 斜率暗示趋势 |
| 空白 + 「未披露」 | 0 / 横线 / 灰块填充 |
| 台账状态字（追踪中/部分兑现/证据不足/证伪） | 进度条、百分比、评分、仪表盘 |

**关掉 CSS 后信息量不得减少**——若减，说明依赖视觉传达结论，违规。

## 5. 红线 P1–P10

| 编号 | 红线 | 判定 |
|---|---|---|
| P1 | 限定语藏在后面 | 只看 L1 是否产生误读 |
| P2 | 制造不存在的矛盾（不同口径数字并置成冲突） | 核两个数字的样本/分母 |
| P3 | 颜色/图形暗示结论 | 关 CSS 后结论不变 |
| P4 | 折叠依据（默认隐藏需点击） | 默认可见 |
| P5 | likelihood / confidence 混写或用模糊修饰 | 逐句查词表 |
| P6 | 复述冒充解释 | 是否写了推理链/替代/确定度/推翻条件 |
| P7 | 无替代解释 | ≥1 + 区分指标 |
| P8 | 跨期关系缺失 | 首次/一致/变更 + 下期核对 |
| P9 | 存量冒充增量 | 每个数字标 new/stock/background |
| P10 | 观测盲区不展示 | 管线自身缺口是否在界面可见（与 R14 成对） |

## 6. 验收 D1–D10

| # | 检查 | 通过标准 |
|---|---|---|
| D1 | 20 秒复述 | 只看 L1 的读者复述出的意思与我们一致 |
| D2 | 独立成篇 | 遮住 L2/L3，L1 成立不误导 |
| D3 | 溯源距离 | 任一句事实 → 原文 ≤1 次点击 |
| D4 | 口径同屏 | L1 每个数字旁可见 `n=` / 窗口 / 分母 / 存量标记 |
| D5 | 纯文本可辨 | 关样式仍分清事实/判断/假设/反证 |
| D6 | 词表合规 | likelihood 全来自七档；confidence 不同句 |
| D7 | 解释完整 | 推理链 + 替代 + 确定度来源 + 推翻条件 |
| D8 | 反证可见 | 削弱判断与未披露项默认可见 |
| D9 | 跨期可见 | 状态 / 下期核对 / 未执行项 / 改判记录 |
| D10 | 无装饰噪音 | 删掉全部图表配色，信息量不减 |

任一不过即退回；工程验收（渲染、响应式、零报错）另算，不能替代。
