# 情报验收标准 · 三 · 解读（Interpretation Standard v2.0）

> 管「我们替读者做的那一步思考，是否成立、是否可被检验」。
> 展示标准管「怎么摆」，本文件管**摆出来的那个「我们怎么读」到底有没有做真正的分析工作**。
> 依据：ICD 203 #3（区分底层情报 vs 分析员的假设与判断）、#4（替代分析）、#7（判断的变化或一致性）、#2（不确定性表述）、CIA Tradecraft Primer 2009（Key Assumptions Check、ACH 的诊断性证据）。

## 0. 判断的最小结构

一条可验收的解读，必须包含六件事，缺一即不算解读：

```
① 底层事实      —— 外部发生了什么（带来源与口径）
② 推理链        —— 从事实到判断的每一步，标明哪一步是推断
③ 关键假设      —— 判断依赖哪些未写出的前提；假设错了判断变成什么
④ 替代解释      —— 至少一个同样能解释事实的假设；什么证据能区分
⑤ 确定度来源    —— 为什么是「很可能/中置信」而不是别的
⑥ 推翻条件      —— 什么具体信号出现，我们就改判
```

只有 ① 的叫简报，只有 ①② 的叫评论，六项齐全才叫情报解读。

## 1. 红线 I1–I9

| 编号 | 红线 | 判据 |
|---|---|---|
| **I1** | **推理链断裂** | 事实与判断之间缺步骤；或某一步其实是常识/直觉而非从材料推出 |
| **I2** | **把归纳当演绎** | 用少数案例推出「行业规律」，未说明样本边界 |
| **I3** | **假设隐性** | 判断依赖的前提没写出来（如「招聘量可代理团队规模」） |
| **I4** | **替代解释缺席** | 只给一种解释；或给了替代但没有区分指标（无法证伪） |
| **I5** | **确定度无据** | 写了「可能/很可能」但未说明依据（源数量、质量、时效、反证） |
| **I6** | **Evidenced 与 Inferred 混淆** | 「数据显示 X」实为「我们推断 X」 |
| **I7** | **不可检验** | 判断没有可观测的推翻条件；怎么发展都能说「符合预期」 |
| **I8** | **过度解释** | 材料只支持「有动作」，解读成「有战略」；只支持「在招」，解读成「已建成」 |
| **I9** | **解读本体越界** | 滑向采购/招聘/组织/成本建议（对应内容标准 R8 的解读侧） |

## 2. 诊断性检验（来自 ACH 的核心）

不是所有证据都算证据。**能区分竞争假设的证据才叫诊断性证据**；与所有假设都相容的材料，只能作为背景。

对每条判断强制回答：

```
本判断的竞争假设：
  H1（我们的）：……
  H2（替代）：……
关键证据 E1..En：
  E_i 与 H1 相容？  与 H2 相容？
  哪些 E 是只与 H1 相容的（诊断性）？
  若没有诊断性证据 → 判断降级为「观察」，不得标 A 级
```

**推论规则**：若无法找到任何只与 H1 相容的证据，则该判断只能写成「观察」（B 级），不得进入结论区。

## 3. 关键假设检查（Key Assumptions Check）

每个判断必须显式列出前提，并写明「若前提不成立，判断变成什么」。示例：

```
假设 A1：公开岗位发布可代理团队组建意图，但不代理团队规模。
  若不成立（岗位可能长期挂空 / 批量复制）：本判断退化为「未见明确扩编信号」。
假设 A2：采集覆盖的 89 个信源能代表公开面。
  若不成立（重要厂商不在采集范围）：本判断只描述已覆盖范围。
```

## 4. 解读的三种合法强度

| 强度 | 条件 | 允许的措辞 |
|---|---|---|
| **观察** | 单源、或无可区分证据、或缺关键口径 | 「我们发现 X 条……尚未判断」 |
| **判断** | 有 ≥2 独立源 + 至少一条诊断性证据 + 替代解释已排除 | 「我们判断……很可能」 |
| **暂定结论** | 判断 + 已观测到至少一次下期核对结果 | 「据此我们认为……，本期核对已确认其中 X」 |

**禁止跳级**：不得从「观察」直接写成「暂定结论」。

## 5. 红线如何在界面体现（与展示标准成对）

| 解读要求 | 界面上必须出现的元素 |
|---|---|
| 推理链 | 「【判断】」段落内标出哪一步是推断 |
| 关键假设 | 「【假设】」区 + 若错后果 |
| 替代解释 | 「【替代解释】」区 + 区分指标 |
| 确定度 | confidence 行 + 一句话依据 |
| 推翻条件 | 「【下期核对】」区，可判定 |
| 强度等级 | L1 角落标 `观察 / 判断 / 暂定结论` |

## 6. 验收 J1–J9

| # | 检查 | 通过标准 |
|---|---|---|
| J1 | 六要素齐全 | ①–⑥ 全在，缺一即退回 |
| J2 | 推理可重走 | 他人仅凭 L2 能否复现同一判断 |
| J3 | 假设显式 | 至少 1 条，且含「若错则判断变成什么」 |
| J4 | 替代可区分 | ≥1 替代 + 具体区分证据 |
| J5 | 诊断性证据存在 | 至少 1 条只与本判断相容的证据；否则降为「观察」 |
| J6 | 确定度有据 | confidence 依据可逐项指出 |
| J7 | 推翻条件可判定 | 含谁/何时/什么动作；不含「持续关注」 |
| J8 | 强度未跳级 | 界面标注等级与证据水平一致 |
| J9 | 无越界 | 全文无采购/招聘/组织/成本建议 |

## 7. 与内容、展示的关系

- 内容标准问「材料能不能用」（R1–R14）
- 解读标准问「从材料到判断这一步做没做对」（I1–I9、J1–J9）
- 展示标准问「摆得对不对」（P1–P10、D1–D10）

**三者全过才可发布。** 内容过、解读不过 = 有材料没分析；解读过、展示不过 = 有分析但传错了；展示过、内容不过 = 好看但站不住。
