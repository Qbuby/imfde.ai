# 情报验收标准 · 一 · 内容（Content Standard v2.0）

> 管「这条情报本身成不成立」。配套：`02-display.md`（怎么摆）、`03-interpretation.md`（怎么解释）、`00-paywall-policy.md`（材料怎么来的）。
> 依据：ICD 203 五项分析标准与九条 tradecraft、ICD 206 来源要求、Admiralty 双轴、Kent 1964、CIA Tradecraft Primer 2009；市场侧见 `docs/research/`。
> **红线一票否决，不看总分。**

## 0. 本体

产品的单位是**一条判断**，不是一条资讯、一个数字、一份报告。判断必须能回答：发生了什么、据此我们判断什么、证据到哪一步、下期拿什么核对。

## 1. 来源与获取（R1–R3）

| 编号 | 红线 | 判据 |
|---|---|---|
| **R1** | **不可回溯** | 每个事实句都能点开原文；并标注**获取方式**（公开 / 免费注册 / 付费订阅 / 授权 / 未取得）。未取得的材料不得出现在事实句或判断句，只能进「待核清单」 |
| **R2** | **绕墙取证** | 使用绕过付费墙/登录墙获得的材料。获取方式本身无法写进来源描述，读者无法复核 → 与 R1 冲突，直接排除。合规替代见 `00-paywall-policy.md` |
| **R3** | **未去重** | 同一公告的多篇转述、同一岗位的多城重复发布、同一案例的多语言镜像，被计为多条独立证据。必须给同源簇 ID，并报告「原始条数 → 去重后条数」 |

## 2. 事实与推断（R4–R6）

| 编号 | 红线 | 判据 |
|---|---|---|
| **R4** | **时态造假** | 宣布≠完成、计划≠结果、在招≠到岗、试点≠上线、合同≠收入。逐句核对动词 |
| **R5** | **空白被填满** | 未披露写成「没有」「为零」「不存在」。只允许写「该来源未披露」 |
| **R6** | **事实与判断混写** | 假设、推论、AI 整理结果被写成事实。必须逐句可辨 `事实 / 判断 / 假设` |

## 3. 口径（R7–R8）

| 编号 | 红线 | 判据 |
|---|---|---|
| **R7** | **口径缺失或混用** | 任何数字必须带三件套：**样本 / 时间窗 / 分母**。不同口径的数字不得相加、平均、排名、并置成对比 |
| **R8** | **存量冒充增量** | 「当前在招总量」「库内案例总数」这类存量被表述为本期新增。必须标明 `本期新增 / 截至某日存量 / 长期背景` |

## 4. 判断品质（R9–R11）

| 编号 | 红线 | 判据 |
|---|---|---|
| **R9** | **无证据的锐利** | 为制造价值感而造矛盾、造冲突、造结论。反直觉判断需 ≥2 个独立源，否则只能标为「观察」 |
| **R10** | **无替代解释** | 判断只给一种解释。至少 1 个合理解释 + 「什么证据能区分二者」 |
| **R11** | **利益立场未披露** | 厂商发布的、关于自身品类的调查被当作独立基准（如 Perspective AI 的 FDE 调查结论利好它自己的工具品类）。L1 必须标立场 |

## 5. 连续性与自我审计（R12–R14）

| 编号 | 红线 | 判据 |
|---|---|---|
| **R12** | **假连续性** | 台账/历史期次/兑现记录是演示数据却按真实呈现。每条必须能回指某期原文与核对日期 |
| **R13** | **下期核对不可判定** | 写「持续关注」。必须是：谁 + 何时 + 什么可观测动作 |
| **R14** | **观测盲区不报** | 本产品的管线自身出错、覆盖缺失、加工中断，却不披露。**自己的证据面出问题必须当情报报出来**，否则后续判断建立在看不见的地基上 |

> R14 是 v2 新增，来自本次实物发现：近 30 天 8 条部署案例事件，**0 条**关联到结构化案例记录，而全库 deploy 事件缺关联仅 6%——说明案例加工管线近一个月没有产出，此前版本未披露这一点。

## 6. 机器可检清单

发布前自动跑，任一 FAIL 即退回：

```
[ ] 每个事实句含 source_id 且 source_url 可达
[ ] 每个 source 含 fetch_mode ∈ {public, free-signup, paid, licensed, unavailable}
[ ] 每个数字含 sample / window / denominator 三字段
[ ] 每个数字含 stock_or_flow ∈ {new, stock, background}
[ ] 去重报告存在：raw_count / unique_count / dup_groups
[ ] 判断句含 likelihood ∈ 七档词表、confidence ∈ {低,中,高}，且不同句
[ ] 判断句含 alternatives ≥1 且含 distinguishing_evidence
[ ] 判断句含 next_check ≥1 且含 who / when / observable_action
[ ] assumption 列表存在，且每条含 if_wrong_consequence
[ ] evidence_status ∈ {verified, abstract-only, snapshot-pending, unverified}
[ ] 若 source 为厂商且结论涉其品类 → 含 conflict_note
[ ] 若本次管线有覆盖缺口 → 含 blind_spot 条目
```

## 7. 评级（过红线后）

内容等级只看三件事，不做加权分数（避免用假精度掩盖判断）：

- **A**：全部红线通过，且至少一条判断的 next_check 可被下期实测。
- **B**：红线通过，但判断属「观察」级（单源或证据不足）。
- **退回**：任一红线命中。

**付费层门槛**：连续 3 期 A，且付费内容是功能（跨期台账 / 全库检索 / 来源快照 / 方法论页，四选三），不是更多同类文章。
