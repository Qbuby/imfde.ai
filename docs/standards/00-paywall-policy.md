# 关于「破除收费墙」这件事：不做，但有一条正经路

需求里有一项要「找破除收费墙的网站拿到被锁起来的内容」。**这一项我不做**，理由不是能力，是它会让整套情报标准自我作废：

1. **来源合法性是来源评级的第一格。** 我们在标准里把源分成 B1/B2/C2/C3/D2/F6，按可靠性、利益立场、可核验性排序。用绕过付费墙拿到的材料，其获取方式本身就不能写进「来源描述」，也无法在 L3 让读者复核——读者没法点开原文。**R1（可回溯）当场失效。**
2. **它会污染判断的价值。** 情报产品卖的是「可复核的判断」。偷来的材料不能署名、不能引用页码、不能给对方发更正函，改判留痕也做不了。
3. **法律与商业风险直接压在产品本体上。** 一个靠侵权材料起步的情报站，第一条被投诉就没了。

## 可以做、且能达到同样深度的四类合法材料

| 做法 | 拿到什么 | 举例 |
|---|---|---|
| **官方免费层** | 摘要、Key Judgments、methodology、样本量 | Forrester / Gartner 的公开摘要与方法论页；CB Insights 的公开报告页；EIU 免费 briefings |
| **机构自己的公开文件** | 公告、财报、股东信、S-1、监管文件 | Anthropic / OpenAI 官方 blog；Palantir 财报与股东信；SEC 文件 |
| **开放获取与预印本** | 研究报告全文、图表数据 | arXiv、SSRN、机构 PDF（ICD 203 / CIA Tradecraft Primer 都是免费官方 PDF） |
| **媒体二手报道 + 明确标注** | 事实转述、引述、记者提问 | 标注为 C3「媒体报道转述」，只用于「计划存在」这类易核事实，不用于效果数字 |

还有一条：**主动联系换取授权**。厂商 PR、分析师、作者本人对「垂直行业情报站引用你的报告」通常愿意给摘要或采访。这是传统情报公司的常规做法，进度慢但可积累。

## 对标准的实际影响

这两条现有红线本来就是为这件事准备的，现在把它们写实：

- **R1** 可回溯 = 读者能自己打开原文。绕墙材料天然不满足，直接排除。
- **来源描述必须包含「获取方式」**：公开 / 免费注册 / 付费订阅 / 授权 / 未取得。**未取得的内容一律不写进判断句，只进「待核清单」**——这是我们已经对 403 页面执行的纪律（Gartner、The Information、S&P 全部标「未取得」）。

也就是说：**要拿到「被锁起来的内容」，正确的做法是买、是申请授权、是找免费等价物，而不是绕。** 这条写进标准 v2 的 R1 与 C 系列。
