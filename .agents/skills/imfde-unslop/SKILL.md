# ImFDE 去 AI 味写作规范

ImFDE 是面向 FDE 的专业社区（X + Contra 级视觉）。界面应该像产品，不像Marketing 落地页。
文案写成真人在用的工具：功能词、平实短语、长短不一的口语。禁止把产品原则反复贴到界面上说教。

## 六类禁用模式

1. **PRD 免责说教泄露**：禁止在首页、页脚、发现页、作品页、注册页反复解释
   「不做信用分 / 不做排名 / 不经手交易 / 展示可观察事实 / 每一条都由作者自己写 /
   不需要认证审核」。产品不放评分组件即可，界面不必嘴碎解释。
   - 事实来源微注只允许在个人主页和作品页极克制出现：「由本人填写」「外部链接」。

2. **否定对比句式**：禁用「不是 X，是 Y」「不做 X，不做 Y，只做 Z」
   「最大的隐形杀手不是 A，而是 B」「无需 X，无需 Y」。

3. **三连排比与短促广告句**：禁用「填一个 X，写一句 Y，贴一个 Z」
   「发动态、关注同行、收藏作品」「两分钟。不需要 A，不需要 B。」

4. **鸡汤 / 文艺 / 公关标题**：页头直接写功能词或平实短语。禁用
   「你的作品，值得被找到」「有人真的把它跑起来了」「找到正在现场做事的人」
   「先把自己放上来」「一个地址，装下你做过的事」。

5. **标点与套话**：中文 UI 严禁长破折号 `—` 拼接卖点；禁止「配得上」「赋能」
   「闭环」「重塑」「一站式」「打造」。

6. **假干货四股文动态**：社区示例动态必须像真人在 X / 即刻随手发的帖子——
   长度参差（十几个字的随口提问到三四行的吐槽），不要每条都套
   「痛点 + 精确百分比 + 人生感悟 + 两个整齐 #Tag」公式。部分帖子不带标签或只带一个。

## 允许的风格

- 页头：`广场` `发现 FDE` `作品` `编辑主页` `外部账号` `隐私设置`。
- 说明：一句平实话，如「按名字、方向或技能查找」「填好标题和简介即可发布」。
- 按钮：`注册` `搜索` `关注` `发布` `查看作品 ↗`。
- 空态：一句话 + 一个动作，不解释平台哲学。
- 种子动态：口语、参差、细节真实；中文英文按人物自然习惯。

## 检查清单（写文案前过一遍）

- 这句话在向用户解释产品原则吗？→ 删。
- 用了「不是…而是…」或三连排比吗？→ 改成平实陈述。
- 标题像广告语吗？→ 换成功能词。
- 示例动态是不是每条都工整带双标签？→ 打散长度与标签数。
